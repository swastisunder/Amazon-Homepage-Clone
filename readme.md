# Amazon Homepage Replica

This project is a static replication of the Amazon homepage layout without using JavaScript. It includes additional features such as hover animations, box shadows, and border radius to enhance the user interface.The project showcases a responsive design inspired by the Amazon website.

## Features

- Accurate reproduction of the Amazon homepage layout.
- Enhanced user interface with hover animations.
- Stylish use of box shadows and border radius.

## Technologies Used

- HTML
- CSS

## Getting Started

1. Clone the repository.
2. Open `index.html` in your browser to explore the Amazon homepage replica.
